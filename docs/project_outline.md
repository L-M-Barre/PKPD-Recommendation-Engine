# PK/PD Recommendation Engine

## Project aim
to create a PK/PD simulation platform that 
- accepts drug selection
- accepts drug formulation
- accepts patient parameters
- simulates PK/PD profiles
- Recommend optimal dosing

## Round 1
system testing before building a database:
- One compartment PK model
- ... test drug
- User inputs: 
    - age
    - weight
    - Dose

## Outputs
graphical/numerical data outputs
- Concentration vs Time graph
- AUC
- Cmax
- Tmax

## Future Features
- Hydrogel formulations
- renal function user input
- population PK
